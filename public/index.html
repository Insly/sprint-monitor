      Home page setup

      Make this your browser home page.

      Page address: https://insly-sprint-monitor.onrender.com

      Edge: Settings > Start, home, and new tabs > When Edge starts > Open these pages > Add a new page > paste the address. For the Home button, set Home button to the same address.

      Chrome: Settings > On startup > Open a specific page or set of pages > Add a new page > paste the address. For the Home button: Settings > Appearance > Show home button > enter the address.

      Neither browser lets you choose a custom new tab page in settings. Your IT admin can set one for everyone.
